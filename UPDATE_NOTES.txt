V20 update
- Supabase setup now creates/upgrades the products and product_images tables and sets public read/admin-only write access.
- Product image storage policies are made admin-only for uploads, updates, and removals.
- Admin product loading now shows a clear database error instead of silently displaying zero.
- Editing a product preserves its current image gallery unless replacement photos or the remove option are selected; replaced/deleted product image files are cleaned up when possible.
- Delivered and cancelled orders can be archived and restored. Archived orders are opened from a compact Archive shortcut in the admin dashboard header, not a persistent tab in the Orders view. Archiving preserves the order row and customer order history.
- Supabase setup adds the archived_at column safely to existing order tables without deleting order data.

- The Orders tab opens on active orders; the header Archive shortcut opens the archived list.

- The dashboard Archive shortcut no longer displays an archived-order count.

V21 update
- The Products breadcrumb is now a link back to the unfiltered All Products page.
- The product listing heading now changes to the selected category, including when a category is opened from a direct URL.

V22 update
- Admin product categories are no longer limited to a fixed dropdown. Enter a new category name or choose an existing suggestion.
- Active product categories now populate the homepage category navigation, homepage category cards, and product listing filters.

V23 update
- Added a Vercel server-side Business Koro product endpoint. It keeps the API key out of browser code and verifies the caller is an authenticated ZENVIX admin before returning supplier catalog and cost data.
- Added an Admin -> Products importer to select supplier products, set a category and customer selling price, and save selected products to Supabase with their images.
- Added a supplier product ID column and unique index to the repeatable Supabase setup SQL to avoid importing duplicate supplier items.
- Business Koro customer order submission is not part of this version; current checkout continues to save orders in ZENVIX only.
